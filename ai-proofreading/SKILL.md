# AI味审校（AI味诊断与必要改写）

本 Skill 通过"先诊断、再改写"的流程，识别文章中的 AI 写作痕迹，并在用户需要时进行必要改写。目标不是伪装成人类，而是让内容更清楚、更具体、更有作者判断。

## 核心目标

1. **识别 AI 写作指纹**：指出具体哪句话有问题，而不是笼统说"AI味重"
2. **保持内容质量**：不改丢核心信息和逻辑
3. **增加真实感**：加入真实细节、个人经历、具体案例
4. **默认只诊断**：用户明确要求"帮我改"后，才进入改写

## 三遍审校流程

### 第零遍：AI 指纹扫描（默认执行）

按文本顺序逐处扫描，不按类型堆清单。每一处必须引用原文，并说明它为什么像 AI。

重点识别以下 22 类 AI 指纹：

1. 堵住所有反驳，显得过度完美
2. 知识全部输出，术语和背景堆太满
3. 匀速排比，句式太整齐
4. 同一个让步模板反复使用
5. 给概念起名字的仪式感过重
6. 情绪曲线太光滑，没有真实毛边
7. 替读者说一句蠢话再纠正
8. "不是 X，而是 Y"高密度出现
9. 没有任何犹豫或不确定
10. 精确到不真实的情绪细节
11. 脆弱感只服务于论点，像被设计过
12. 把复杂结论包装成"协议/公式/清单"
13. 每个段落都收束成金句
14. 句子节奏过于均匀
15. 用身体感受替代论证
16. 开头"钩子 + 痛点 + 承诺"三件套太标准
17. 连接词过度使用且位置固定
18. 同义词刻意替换，反而不自然
19. 段落结构完全对称
20. 观点过度中立，不敢判断
21. 例子虚泛，没有可验证细节
22. 结尾拔高过度，像通用总结模板

输出格式：

```markdown
# AI 写作指纹检测报告

**命中 X 处 AI 指纹**

**第 1 处**

> {直接引用原文}

{一两句话说明问题}
`特征 #N / 严重度：强/中/弱`

---

**总结**：{一两句话概括最突出的问题}

以上是检测结果，尚未改写。如果需要我改，继续说"帮我改"。
```

### 第一遍：内容审校

检查以下内容：

- **事实准确性**：核实所有数据、日期、人名、地名的准确性
- **逻辑清晰性**：确保论证链条完整，没有逻辑跳跃
- **无编造信息**：不要编造不存在的引用、数据或案例
- **原创性检查**：确保不是直接复制网络内容

### 第二遍：风格审校（核心）

识别并改写以下6大类AI腔：

#### AI腔类型1：套话连篇
**问题表现**：
- "在当今XX飞速发展的时代"
- "随着社会的不断进步"
- "我们需要认识到XX的重要性"
- "值得一提的是"
- "综上所述"

**改写方法**：直接切入主题，删除套话

**示例**：
- ❌ "在当今AI技术飞速发展的时代，我们不得不思考..."
- ✅ "AI发展太快了。我们不得不思考..."

#### AI腔类型2：AI句式
**问题表现**：
- **翻案句全族**——同一个毛病换壳，7 种一起查，不是只查第一种：

  | 句式 | 处理 |
  |-----|------|
  | 不是……而是…… | 直接说清楚是什么，省掉对比结构 |
  | 并非……而是…… | 同上 |
  | 不在于……而在于…… | 同上 |
  | 与其说……不如说…… | 同上 |
  | 不只……还／也…… | 拆成两句陈述 |
  | 表面……实际／其实…… | 直接写实际情况 |
  | 看似……实则…… | 直接写实际情况 |

- "首先...其次...最后..."的机械结构
- "一方面...另一方面..."套用
- 过度使用衔接词

**改写方法**：拆长句为短句，自然连接。改翻案句时**先找出它原本想说的事实，用普通句子说出来，不要换另一种漂亮句式替换。**

**示例**：
- ❌ "AI不是替代人类的工具，而是增强人类能力的伙伴。"
- ✅ "AI不会替代人类。但它能增强我们的能力。"

#### AI腔类型3：书面词汇
**问题表现**：
- "显著" → "很明显"
- "实现" → "做到"
- "应当" → "应该"
- "以及" → "和"
- "因此" → "所以"
- "然而" → "但是"

**改写方法**：用口语化词汇替换书面语

#### AI腔类型4：结构机械
**问题表现**：
- 每个段落长度相近
- 每个观点都有"首先、其次、最后"
- 标题和内容完全对应

**改写方法**：段落长短交替，结构自然

**示例**：
- 短段落（2-3句）用于强调
- 长段落（5-8句）用于展开
- 打破对称结构

#### AI腔类型5：态度中立
**问题表现**：
- "XX有一定道理，但也存在局限"
- "一方面...另一方面..."（各打五十大板）
- 缺乏明确立场

**改写方法**：表达明确观点，敢于判断

**示例**：
- ❌ "有人说AI会取代程序员，有人说不会。我认为两种观点都有道理。"
- ✅ "AI不会取代程序员，但会改变程序员的工作方式。"

#### AI腔类型6：细节缺失（改法有硬边界）
**问题表现**：
- 抽象描述多，具体例子少
- 时间模糊（"最近"而不是具体日期）
- 人物模糊（"一个朋友"而不是具体人）
- 数据模糊（"很多"而不是具体数字）

**改写方法**：加入真实细节。**具体只能来自材料，材料里没有就不许补。**

**示例**：
- ❌ "最近很多公司开始使用AI。"
- ✅ "上周，我知道的3家创业公司都已经用上了AI编程助手。"（前提：这3家真实存在）

> ⚠️ **假细节越具体，AI味越重。** 没有来路的精确时间、天气、神态、房间摆设、突然出现的对白，全是假细节。凌晨三点、第三根烟、桌上的冷咖啡、窗外的雨，如果没有来源也不改变后文，删掉，不要换一个新的填进去。真人写不出那么整齐的道具。

**编不出来时的正确处理**：保持模糊，或整句删掉，或去补材料。**不能靠编细节假装亲历。**

**留不留的唯一判据**：这个细节改变了读者对这件事的理解吗？一笔价格能说明风险，一段原话能说明关系，一次失败能说明旧办法为什么行不通——留。只负责让画面显得真实的——删。

### 第三遍：细节打磨

**句子长度**：
- 平均句长15-25字
- 长句拆成短句
- 使用短句增加节奏感

**段落长度**：
- 公众号/手机阅读：3-5行/段
- 控制在手机屏幕3-5行可见范围内
- 避免长段落（超过8行）

**标点节奏**：
- 多用句号，少用分号
- 适当使用问句增加互动感
- 感叹号表达态度（但不要过度）

**加粗使用**：
- 每200-300字1-2处加粗
- 只加粗核心关键词
- 不要过度加粗

### 第四遍：传播力审校（公众号爆款检查）

**D1 标题力**（打开率目标 ≥ 10%）
- [ ] 标题命中"信息差/情绪触发/具体数字"≥ 2/3
- [ ] 封面图有视觉差异化，非通用素材图

**D2 钩子力**（完读率目标 ≥ 30%）
- [ ] 前 3 行无铺垫废话，直接给出"这篇和你有关"信号
- [ ] 开场含数据冲击 / 场景痛点 / 反直觉结论之一

**D3 密度与节奏**（收藏率目标 ≥ 3%）
- [ ] 段落控制在 2-4 行，无超过 6 行大段
- [ ] 有可回收干货（清单/操作步骤/对比表）

**D4 情绪传播**（分享率目标 ≥ 5%）
- [ ] 至少触发一种强传播情绪：愤怒/焦虑/自豪/感动
- [ ] 有"读者转发时想表达什么"的设计

**D5 互动引导**（评论率目标 ≥ 1%）
- [ ] 正文埋 1 个开放式问题 或 争议性判断
- [ ] 结尾有显式互动引导（非"欢迎点赞关注"）

**D6 关注转化**（吸粉率目标 1-3%）
- [ ] 有系列感 / 资源钩子 / 人设差异化 至少一项

**D7 传播裂变**（二次传播目标 ≥ 60%）
- [ ] 至少 1 个可截图传播信息单元（金句/数据图/对比表）

---

## 检查清单

完成四遍审校后，逐项核对：

- [ ] 套话已删除或改写
- [ ] 机械句式已拆分
- [ ] 书面词汇已口语化
- [ ] 段落长度合适（2-4行）
- [ ] 加粗不超过2处/200字
- [ ] 有真实细节和案例
- [ ] 态度明确，不中庸
- [ ] 像真人在说话
- [ ] 传播力7维达标 ≥ 5/7

如果用户只要求检测，输出"AI 写作指纹检测报告"即可。

## 注意事项

1. **不要改变核心观点**：改写风格，不改观点
2. **不要添加虚假信息**：所有细节必须是真实或合理推断
3. **保持一致性**：确保全文风格统一
4. **尊重原文**：只改必要的部分，不过度编辑
