### 🚀 Phase 5: 多平台分发 (Multi-Platform Distribution)

**步骤 5.1 - 询问分发需求**

询问用户：
```
文章已完成！是否需要为其他平台生成内容？

支持平台：
1. X / Twitter（Thread 形式）
2. 小红书（种草风格）
3. Instagram（视觉故事）
4. 微信公众号（图文排版）

请告诉我需要分发到哪些平台，或直接说"全平台分发"。
```

**步骤 5.2 - 调用 content-converter**

根据用户选择，调用 `content-converter` Skill 生成各平台内容：

**X / Twitter Thread**:
- 提取核心 3-5 个观点
- 每条 X 包含一个完整观点
- 设计吸引眼球的 Hook
- 最后一条引导关注

**小红书**:
- 真实体验 + 干货分享
- 种草属性
- Emoji 点缀 + 分段清晰

**Instagram**:
- 视觉优先 + 配图精美
- 简短文案（前 2 行最关键）
- 话题标签（5-10 个）
- Stories 版本（分屏展示要点）

**微信公众号**:
- 图文排版优化（适合公众号阅读）
- 段落间距 + 字体大小建议
- 引导关注/转发/点赞
- 首图 + 次图建议

输出：
```
【多平台内容生成完成】

已生成：
- ✅ X Thread（X 条）
- ✅ 小红书笔记（1 篇）
- ✅ Instagram 文案 + Stories（1 组）
- ✅ 微信公众号排版建议（1 份）

---

[输出各平台内容]
```
